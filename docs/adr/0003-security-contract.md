# ADR 0003: The security contract

- Status: accepted
- Date: 2026-10-27
- Source: [clone-and-run plan](../CLONE-AND-RUN-PLAN.md) section 7, which states
  the contract in full. This record explains the decision and how M0 built it.

## Context

A markdown viewer opens untrusted files: downloaded repositories, email
attachments, AI output. Markdown previewers have shipped code-execution bugs
(Markdown Preview Enhanced had four CVEs in 2026; Typora had an RCE via a
crafted file). Remote images leak that a file was opened, and on Windows a
`file://` or UNC reference can leak credentials.

## Decision

Defense in depth, with every layer testable:

1. **No network.** The v1 binary makes no network connections. Remote
   resources referenced by a document are never loaded; the CSP `img-src`
   allows only the app's asset scheme and `data:`. Opt-in remote loading is a
   v1.1 decision with its own ADR.
2. **Sanitizer.** Everything that leaves `mdcore` is sanitized by ammonia.
   URL-bearing attributes are covered on every element. Links keep only
   `https`, `mailto`, fragments, and relative paths; images keep only local
   references rewritten into the asset scheme.
3. **CSP.** `default-src 'none'`, scripts only from the bundled app, no
   frames, objects, forms, or `base-uri`, `connect-src` limited to Tauri IPC.
4. **One boundary validator.** The active root is Rust-owned state, set only
   by an argv path, a Tauri drag-drop, an OS open event, or a native dialog.
   Every local reference goes through one function: raw gate, percent-decode
   exactly once, inspect (schemes, UNC and device paths, NUL) before any
   filesystem call, canonicalize, compare with the root.
5. **Navigation.** The webview never leaves the app page: link clicks are
   intercepted, and a Rust navigation handler denies everything else.
6. **IPC.** Few, narrow commands, each enrolled in the ACL and granted only to
   the main window. No command takes a trust flag or sets the root. No shell,
   filesystem, or HTTP plugin.

## How M0 implements it

- **The ACL is opt-in in Tauri.** App commands are not checked against
  capabilities at all unless the app declares an app manifest. `build.rs`
  declares one, which also means `capabilities/main.json` cannot reference a
  command that is not enrolled: the build fails instead.
- **Asset URLs carry a hex-encoded raw reference** (`/<generation>/<hex>`), so
  the webview cannot normalise `..` segments or add a second percent-encoding
  layer. The handler undoes only the hex transport, then runs the same
  validator as the renderer, independently. It serves image types only, with
  `nosniff`, and refuses stale generations.
- **Windows path forms** are inspected before the filesystem: drive-relative
  paths, alternate data streams, and reserved device names (`NUL`, `COM1`) are
  refused, because opening them reaches a device rather than a file.
- **The harness never ships.** The `test-harness` feature adds a CSP-violation
  listener (an initialization script that lives outside `ui/`), a raw-HTML
  injection command, and a stdout results channel. Harness commands enter the
  ACL only under the feature, and `build.rs` deletes their stale generated
  permission files otherwise, because tauri-build reads every file in
  `permissions/autogenerated` and never cleans it. CI checks the production
  binary for every harness marker, with a positive control on the harness
  binary.

## Evidence standard

The harness proves narrow things: a fixture's attempted loads were blocked by
an enforced CSP and reached no loopback listener, and a denied command was
rejected through the real webview IPC path. It does not prove the absence of
all outbound traffic from the process. The broader "no network" claim rests
on the CSP, on the app code containing no networking calls, and on no network
plugins being enabled, and the README states it at that level of evidence.

## Consequences

- READMEs with remote badges show placeholders in v1. That is the price of an
  absolute network claim.
- Every new command, attribute, or scheme is a change to this contract and
  needs a test in the matching corpus.
